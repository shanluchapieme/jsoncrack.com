# Product Identity

**Internal/product name: Since Tomorrow Market Explorer.**

This is not "JSON Crack." JSON Crack is upstream renderer ancestry only — see
`UPSTREAM_LINEAGE.md`. The product ships with Since Tomorrow's own visual
language, not the upstream green JSON Crack identity.

## Visual language

- Palette: black, tomato, ivory (Since Tomorrow's known existing brand direction — no separate brand-token file was found elsewhere in `since-tomorrow-os` at time of writing; this is the working default until a canonical token file is located/authored).
- No upstream JSON Crack logo, wordmark, or favicon is reused.

## What it is

A typed market-graph explorer over Since Tomorrow's own canonical evidence
(the `since-tomorrow-os` authority repo), built on a forked, relicensed-compliant
copy of the JSON Crack graph-rendering engine. It reads real formation graphs,
canary registries, and control-plane decisions through a read-only local API
bridge — it does not invent its own source of truth.
